# Understanding ICERs in Healthcare Decision-Making

## Overview
This project explores how incremental cost-effectiveness ratios (ICERs) are used in healthcare reimbursement and HTA decision-making.

## Topics Covered
- Incremental costs and outcomes
- Willingness-to-pay thresholds
- Decision uncertainty
- Limitations of ICER interpretation

## Why This Matters
ICERs are widely used to support reimbursement and healthcare resource allocation decisions. However, interpreting ICERs requires understanding uncertainty, assumptions and broader healthcare implications.

## Skills Demonstrated
- HTA concepts
- Evidence interpretation
- Structured analytical thinking
- Scientific communication
