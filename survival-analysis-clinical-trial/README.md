# Survival Analysis of Clinical Trial Data

## Objective
This project demonstrates survival analysis methods commonly used in health economics and outcomes research (HEOR), including Kaplan–Meier estimation, log-rank testing and Cox proportional hazards modelling.

## Methods
- Kaplan–Meier survival curves
- Log-rank test
- Cox proportional hazards model
- Hazard ratio interpretation

## Dataset
Veterans' Administration Lung Cancer dataset from the R `survival` package.

## Software
- R
- survival
- survminer
- dplyr

## Key Skills Demonstrated
- Time-to-event analysis
- Clinical trial analytics
- Comparative effectiveness interpretation
- Survival modelling
- Data visualisation
