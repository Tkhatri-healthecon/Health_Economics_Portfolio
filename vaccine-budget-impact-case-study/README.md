Vaccine Budget Impact Case Study
Overview

This project presents a sanitised health economics case study demonstrating the structure of a budget impact analysis for introducing a vaccine programme.

The original academic model is not shared because it may be used for future publication. This repository therefore uses a simplified demonstration structure, synthetic inputs and illustrative outputs to show the modelling approach while protecting unpublished work.

Objective

To demonstrate how a budget impact model can estimate the financial implications of phased vaccine introduction across a defined population over a multi-year time horizon.
